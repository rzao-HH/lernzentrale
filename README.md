# Robins Lernzentrale

Lern-Web-App (Winkel-Akademie, Wasser-Zauberschule, Küsten-Crew, Detektiv-Büro) als eine Datei: `index.html`.

- **Adresse:** https://rzao-hh.github.io/lernzentrale/ (GitHub Pages, Branch `main`, Ordner `/`)
- **Speicher:** lokal im Browser (localStorage) + Lerngruppen-Sync über Supabase (Projekt `lernzentrale`, Tabelle `lz_kv`, Funktionen `lz_pull` / `lz_push`).
- **Lerngruppe:** Code (mind. 12 Zeichen) wird pro Gerät einmal eingegeben; er steht nicht im Code.
- **Updates:** neue `index.html` committen – die Adresse bleibt gleich, der Speicher bleibt erhalten.
